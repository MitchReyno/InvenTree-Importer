# Implementation notes

One or two sentences: what was delivered, through which PRs, and what remains.

## Changes to the plan

Where implementation departed from the proposal, specs, design or tasks. Say what the plan said, what was done instead and why, and which artifact was updated to match. Write None if the plan held.

- **YYYY-MM-DD, task N (PR-X):** What changed, why, and the artifact updated.

## Unexpected challenges

Problems the plan did not anticipate, their cause and how they were resolved. Keep only what a later reader would otherwise rediscover the hard way.

- **YYYY-MM-DD, task N:** Problem, cause, resolution.

## Decisions made during implementation

Choices the design left open: a package or version chosen, a trade-off taken, a behaviour pinned down. Include the alternative that was rejected.

- **YYYY-MM-DD, task N:** Decision, rejected alternative, reason.

## Open items

Known limitations, deferred work and follow-ups, with where each is tracked. Write None when nothing remains.
