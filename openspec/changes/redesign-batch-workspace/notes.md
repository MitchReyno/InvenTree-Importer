- **2026-11-06, PR-C (browser):** `Modal` had no background, so it was white in dark mode (also the evidence viewer); it now uses the surface token. - **2026-11-06, task 8.4 (PR-D):** `add_lot` takes no client ID, so "New lot from this" links the file once the refreshed batch shows a new lot whose label matches, and clears the pending link when the edit reports failure. The server stores `add_lot` labels unchanged, so the match holds.

The Map walks predecessors from the operator review's retired lots to the server's depth of 100 and shows inherited files as "via earlier lot" with no Unlink; Part-derived links show "via shared Part".
