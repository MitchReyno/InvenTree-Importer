# Batch settings overhaul

Full planning artifacts for [BI-003](../../../../docs/PLANNED_FUNCTIONALITY.md#bi-003--batch-settings-overhaul): [proposal](proposal.md), [design](design.md), [tasks and PR bundles](tasks.md), [settings delta](specs/capture-batch-settings/spec.md), [reference-selection delta](specs/capture-reference-selection/spec.md) and [inference-preference delta](specs/capture-inference-preferences/spec.md).

Use the original mockup Capture layout by default and remove the Physical lots and Part proposals panes. Simplify settings with optional notes, a searchable single Default location and supplier, safe connected autosave, reviewed evidence-derived quantities and shared Part-tag intent. PO creation and automatic logo discovery remain disabled and captured as separate future items. This is a proposal, not implemented behaviour.
