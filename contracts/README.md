# First-slice runtime contracts

`src/index.ts` is the strict runtime-schema source. `generated/openapi.json`, `generated/api.d.ts` and the generated two-route client are reproducible outputs (`pnpm contracts:generate`; verify with `pnpm contracts:check`). The generated client validates returned DTOs; TS declarations alone never validate data. OpenAPI advertises **only implemented GET endpoints**. Components freeze tested first-slice command/projection shapes for T02/T03/T04; fixture echo tests do not turn them into application routes or authorization. JSON Schema Draft 2020-12 worker envelopes are independently versioned `bench-intake-worker/1`, distinct from HTTP `bench-intake-app/1` and canonical encoding `bench-intake-canonical/1`.

Boundaries preserve unknown/omitted versus `inherit`, `clear` and `set`. IDs are validated lowercase UUIDs; revisions/PKs are positive signed-64-bit strings and cursors may be zero. Quantity strings are positive, canonical, at most 13 integer/6 fractional digits; no numbers, exponent, sign, trailing fractional zeros or whitespace. Explicit Part/location references carry target-context and retained observation identity, not raw browser target URLs. Selected lot arrays reject duplicates and remain ordered at parsing; selected-scope owners sort them as sets before semantic canonicalization. Batch/lot/Part selection, preparation, exact digest approval, cancellation, truthful run certainty/cursor and progress/terminal worker examples traverse actual HTTP in server tests.

`src/json.ts` is a server-only strict JSON/retained-document helper; browser consumers import the runtime schemas/client, not its Node byte-count helper. It rejects decoded duplicate keys even if their values match, reserved prototype keys, unsafe/nonfinite numeric literals, comments/trailing commas, depth over 64 and payloads over 256 KiB. Canonical v1 preserves Unicode rather than silently normalizing human text; its exact Unicode UTF-8/hash vector is retained in `vectors/canonical-v1.json` and round-tripped through real PG. Canonicalization is not a general JSON serializer: domain number values must already be schema-authorized strings, and schema-defined sets must be sorted by the owning command.

The narrowed worker envelope supports only progress/running or terminal/completed/interrupted messages. Authentication, sequence ownership, input freshness, proposal/question shapes and accepted-result persistence belong to T06. These examples must not be mistaken for a complete provider protocol or approval grant. `RunSnapshot` is the minimum polling/certainty contract; operation/effect detail and recovery actions are extended with T03/T04 through the coordinator, preserving version compatibility rather than silently interpreting unknown fields. Follow the server's [boundary-focused testing guidelines](../intake-server/TESTING.md) when changing these schemas. The `.cjs` generator runs directly on pinned Node and consumes this runtime TypeScript schema source through Node's native type stripping, not an application/bundler loader.
